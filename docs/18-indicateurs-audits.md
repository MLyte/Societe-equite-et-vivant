# Indicateurs, audits et mesure des résultats

## Pourquoi ce document existe

Ce document définit comment Société, équité et vivant mesure ses résultats, détecte ses erreurs et corrige ses politiques.

Un modèle fondé sur la science, l'IA publique, les audits et la démocratie d'arbitrage doit préciser ce qu'il mesure, qui mesure, qui contrôle les mesures et comment une mesure peut être contestée.

---

## Constat actuel

Les décisions publiques sont souvent évaluées par des indicateurs incomplets : croissance du PIB, déficit, taux d'emploi, nombre de bénéficiaires, coûts budgétaires immédiats ou objectifs administratifs internes.

Ces indicateurs peuvent masquer :

- dignité réelle des conditions de vie ;
- accès effectif au socle vital ;
- inégalités territoriales ;
- santé mentale ;
- qualité écologique ;
- résilience aux crises ;
- capture institutionnelle ;
- qualité démocratique ;
- effets différés sur les générations futures.

Un autre risque est la manipulation des indicateurs : lorsqu'un chiffre devient une cible, les institutions peuvent optimiser le chiffre plutôt que la réalité qu'il prétend mesurer.

---

## Objectifs

Le modèle doit :

- mesurer l'accès réel au socle vital ;
- suivre les limites écologiques et sanitaires ;
- détecter les inégalités sociales et territoriales ;
- mesurer la résilience des secteurs vitaux ;
- rendre visibles les erreurs, incertitudes et effets indésirables ;
- auditer les modèles scientifiques et algorithmiques ;
- permettre la contestation des indicateurs ;
- éviter que les tableaux de bord remplacent le jugement démocratique ;
- réduire les incitations à manipuler les chiffres.

---

## Proposition

Société, équité et vivant retient une doctrine de mesure pluraliste et contestable.

Aucun indicateur unique ne peut résumer la qualité d'une société. Le modèle doit utiliser un tableau d'indicateurs limité, public, stable mais révisable, complété par des audits qualitatifs et des retours de terrain.

### Noyau d'indicateurs prioritaires

La version actuelle retient huit familles d'indicateurs.

1. Socle vital :
   - logement sain ;
   - alimentation de base ;
   - eau potable ;
   - énergie minimale ;
   - soins essentiels ;
   - médicaments essentiels ;
   - internet ;
   - mobilité de base.

2. Dignité et droits :
   - recours effectifs ;
   - délais de justice ;
   - discriminations ;
   - expulsions sans solution ;
   - non-recours aux droits ;
   - qualité de l'accueil administratif.

3. Santé et éducation :
   - accès aux soins ;
   - santé mentale ;
   - délais de prise en charge ;
   - maîtrise des savoirs fondamentaux ;
   - culture scientifique ;
   - accès à la formation continue.

4. Écologie :
   - climat ;
   - biodiversité ;
   - eau ;
   - sols ;
   - air ;
   - matériaux critiques ;
   - pollutions persistantes.

5. Résilience :
   - stocks vitaux ;
   - dépendances critiques ;
   - capacité de maintenance ;
   - diversité des fournisseurs ;
   - temps de rétablissement après crise ;
   - redondance des infrastructures.

6. Économie utile :
   - investissements long terme ;
   - rente et spéculation ;
   - accès aux biens essentiels ;
   - activités utiles hors emploi classique ;
   - partage des gains liés à l'automatisation.

7. Démocratie et information :
   - concentration médiatique ;
   - transparence des financements ;
   - participation effective ;
   - compréhension des décisions ;
   - recours citoyens ;
   - exposition aux manipulations organisées.

8. Capture et intégrité :
   - conflits d'intérêts ;
   - portes tournantes ;
   - dépendance aux lobbies ;
   - opacité des bénéficiaires ;
   - concentration de pouvoir administratif, économique ou algorithmique.

### Indicateurs et seuils

Chaque indicateur doit préciser :

- ce qu'il mesure ;
- ce qu'il ne mesure pas ;
- sa source ;
- sa fréquence ;
- son incertitude ;
- les groupes ou territoires concernés ;
- les risques de manipulation ;
- l'institution responsable ;
- les voies de contestation.

Les seuils critiques doivent être distingués des objectifs politiques.

Un seuil critique signale un risque inacceptable pour le socle vital, les droits fondamentaux, la santé, l'écologie ou la résilience. Un objectif politique exprime une priorité démocratique à l'intérieur des limites établies.

### Audit indépendant

Le modèle retient trois niveaux d'audit.

1. Audit technique :
   - données ;
   - modèles ;
   - méthodes statistiques ;
   - systèmes d'IA ;
   - hypothèses ;
   - marges d'erreur.

2. Audit institutionnel :
   - conflits d'intérêts ;
   - financement ;
   - gouvernance ;
   - indépendance ;
   - respect des procédures ;
   - publication des désaccords.

3. Audit social et territorial :
   - effets sur les personnes ;
   - accès réel aux droits ;
   - impacts sur les métiers ;
   - effets locaux ;
   - retours d'expérience ;
   - effets non prévus.

Ces audits doivent être réalisés par des institutions séparées des organismes qui conçoivent ou appliquent les politiques.

### Mesure quantitative et retour qualitatif

Le modèle refuse l'idée qu'un tableau de bord puisse tout dire.

Les chiffres doivent être complétés par :

- enquêtes de terrain ;
- panels citoyens ;
- témoignages structurés ;
- retours des professionnels ;
- contrôles aléatoires ;
- évaluations contradictoires ;
- analyse des recours déposés.

Une politique peut atteindre ses indicateurs tout en produisant une injustice concrète. Dans ce cas, le retour qualitatif doit pouvoir déclencher une révision.

### Risque de manipulation des indicateurs

Société, équité et vivant reconnaît un risque classique de pilotage par indicateur : lorsqu'une mesure devient un objectif rigide, elle peut cesser de mesurer correctement la réalité.

Pour limiter ce risque :

- ne pas utiliser un indicateur unique ;
- publier les méthodes ;
- auditer les données sources ;
- comparer indicateurs quantitatifs et retours qualitatifs ;
- faire tourner certains contrôles ;
- protéger les lanceurs d'alerte ;
- documenter les effets pervers ;
- permettre à des chercheurs, journalistes et citoyens qualifiés de contester les chiffres.

### Obligation de correction

Les indicateurs ne doivent pas seulement informer.

Certains seuils doivent déclencher une obligation de réponse :

- accès insuffisant au socle vital ;
- dépassement d'un budget écologique critique ;
- hausse forte d'une dépendance vitale ;
- délai de recours excessif ;
- concentration dangereuse d'un secteur essentiel ;
- échec répété d'un modèle validé ;
- discrimination ou effet social injuste documenté.

La réponse peut être une correction, une suspension, une révision du modèle, un audit externe, une compensation ou une procédure démocratique de réarbitrage.

### Publication et lisibilité

Chaque politique importante doit publier une fiche de lisibilité :

- objectif ;
- indicateurs retenus ;
- seuils critiques ;
- risques connus ;
- alternatives rejetées ;
- coût ;
- effets sociaux ;
- effets écologiques ;
- institution responsable ;
- audit prévu ;
- procédure de recours.

La lisibilité institutionnelle est un garde-fou démocratique, pas un outil de communication.

---

## Justification

Un modèle qui prétend agir selon le réel doit accepter d'être mesuré par le réel.

Mais mesurer ne suffit pas. Il faut rendre les mesures contestables, pluralistes, compréhensibles et reliées à des mécanismes de correction.

La décision retenue est donc une mesure orientée vers l'apprentissage institutionnel, non vers la communication de performance.

---

## Alternatives étudiées

### PIB et indicateurs économiques classiques

Ils restent utiles pour certaines analyses, mais ne suffisent pas à mesurer la dignité, la santé, les limites écologiques, la résilience ou la capture.

### Score social unique

Cette option est rejetée.

Un score unique simplifie la communication mais écrase les arbitrages, favorise la manipulation et peut devenir un outil de contrôle social.

### Audit purement interne

Moins coûteux et plus rapide, mais insuffisant lorsque l'institution évaluée a intérêt à défendre son propre résultat.

### Mesure entièrement citoyenne

Renforce la participation, mais ne remplace pas les compétences techniques nécessaires pour auditer données, modèles, incertitudes et systèmes complexes.

---

## Critiques

- Trop d'indicateurs peuvent rendre le modèle illisible.
- Les audits peuvent devenir coûteux, lents ou bureaucratiques.
- Les institutions peuvent apprendre à optimiser les chiffres plutôt que les résultats.
- Les données nécessaires peuvent menacer la vie privée si elles sont trop fines.
- Les indicateurs peuvent être capturés par les experts qui les définissent.
- Les seuils critiques peuvent devenir trop rigides en situation exceptionnelle.
- Les retours qualitatifs peuvent être instrumentalisés s'ils ne sont pas structurés.

---

## Questions ouvertes

- Faut-il créer un tableau public unique limité à vingt indicateurs nationaux prioritaires ?
- Faut-il rendre certains seuils juridiquement opposables ?
- Faut-il donner aux citoyens un droit de déclencher un audit lorsqu'un seuil est contesté ?

---

## Ce qui pourrait nous faire changer d'avis

Ce chapitre devrait être révisé si les indicateurs deviennent illisibles, s'ils favorisent la surveillance, s'ils sont capturés par les institutions auditées, ou s'ils échouent à déclencher des corrections réelles.
